# Map boundary attribution

The Metro Manila city and barangay GeoJSON files in this directory are low-resolution 2023 administrative-boundary extracts from [faeldon/philippines-json-maps](https://github.com/faeldon/philippines-json-maps). The required MIT notice is included in `LICENSE.faeldon.txt`; the upstream license is also available [online](https://github.com/faeldon/philippines-json-maps/blob/master/LICENSE).

The source repository states that its administrative data uses Philippine Standard Geographic Code (PSGC) information updated through 31 December 2023. Boundaries are provided for demonstration and must not be treated as current legal or surveying boundaries.

City of Manila barangay geometry is not present in the selected low-resolution source file, so the prototype shows a clear unavailable-data message instead of inventing boundaries.

Content was rephrased for compliance with licensing restrictions.
